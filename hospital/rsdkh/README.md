# Modul Khusus RSDKH

Folder ini disiapkan untuk fitur yang hanya berlaku pada RSDKH, misalnya:

- auto input hasil SOAP ke eRM RSDKH;
- mapping selector/field eRM RSDKH;
- validasi sebelum overwrite data;
- menu tambahan khusus workflow RSDKH.

Jangan menaruh logic umum Magic SOAP/Kronologi di folder ini. Logic umum tetap mengikuti upstream `magic-soap`.
